## 2. End-to-End Pipeline Integration (`test_end_to_end_pipeline.cpp`)

1. **Clean Purchase Lifecycle**: Validates that legitimate transactions ($50.00) flow seamlessly through `FeatureExtractor` $\to$ `FraudDetectorEngine` $\to$ `RiskEngine` $\to$ `DecisionEngine` $\to$ `TransactionService`, updating account balances and appending to the audit log.
2. **Fraud Detection & Dispute Workflow**: Verifies that impossible-travel / blacklisted IP transactions trigger alerts, risk score $> 85$, `BLOCK`/`REVIEW` decisions, generate analyst review cases via `CaseManager`, store verified `GroundTruthRecord` objects in `LabelStore`, and export retraining CSV datasets.
3. **Multi-Scenario Stress Simulation**: Validates stream ingestion of 100 mixed transactions generated by `TransactionSimulator` with zero unhandled exceptions.
4. **Resilient Predictor Fallback Integration**: Guarantees graceful fallback under crashing ML dependencies in `FAIL_OPEN` and `FAIL_CLOSED` modes.
